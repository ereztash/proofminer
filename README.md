# ProofMiner

ProofMiner is a Hebrew RTL MVP for mining existing evidence of expertise, ranking it by social leverage for a chosen ICP and goal, and turning selected proof into evidence-grounded LinkedIn posts.

## Core flow

Source assets → atomic Proof Units → Social Leverage ranking → Top 3 opportunities → LinkedIn post angles.

The product is intentionally not positioned as a generic content generator. Its primary value is discovering overlooked proof that already exists.

## Run locally

```bash
npm install
npm run dev
```
