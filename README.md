# ProofMiner

ProofMiner is currently being rebuilt as a **Personal Decision Intelligence** architecture with a deliberately narrow first commercial vertical:

> **Professional Authority / Market Position for independent experts, consultants and fractional leaders in transition.**

The product is not being broadened to generic life decisions at this stage.

## Current conscious problem hypothesis

> **I know I need to change how the market sees / chooses me, I have many plausible things I could do, but I do not know which move deserves my limited time, money and attention now — or what should wait.**

The product must help the user improve both **representation** (how they understand the bottleneck, dependencies and change conditions) and **allocation** (what receives scarce resources), without replacing the user's authorship of the decision.

## Category hierarchy

```text
Personal Decision Intelligence
→ Professional Authority / Market Position
→ independent experts / consultants / fractional leaders in transition
→ continuous strategic representation + allocation + learning
→ event-driven retention + compounding decision lineage
```

`Personalized Decision Intelligence`, decision profiles, specialized frameworks, scenario comparison and decision history already exist in the market. These are not defensible differentiation by themselves.

## Current state model

```text
A1 — authority need + plausible actions + uncertain representation/allocation
→ freeze project boundary + counterfactual representation/allocation
→ decide how this decision should be decided
→ grounded, contestable allocation decision
→ user commitment + real-world action
→ evidence across affected authority surfaces
→ revised representation / allocation
↺
```

The Authority Map is an explanation/navigation artifact. User agreement is not evidence of decision authorship.

## Measurement

Observe separately:

- Representation Delta
- Decision Authorship / Contestability
- Decision Delta
- Priority Delta
- Resource Allocation Delta
- Premature-Work Reallocation
- New-Leverage Allocation
- Reversal / Regret

`Counterfactual Resource Allocation Delta` is observational only:

```text
measurement_use: observational / evaluation
routing_use: prohibited
governance_use_as_optimization_target: prohibited
```

## Business model hypotheses

```text
Self-serve decision layer        $39–$79 / month
Professional Intelligence       $99–$249 / month
Assisted / human-in-loop         $300–$1,000+ / month
Setup + subscription             $500–$1,500 setup + $99–$249 / month
```

These are FIELD hypotheses, not validated prices. Subscription is not an invariant; episodic Decision Reviews or 90-day engagements remain live alternatives.

## Retention thesis

Reject daily engagement as a product goal. Retention should be triggered by:

- `NEW_DECISION`
- `NEW_EVIDENCE`
- `OUTCOME_RETURNED`
- `DEPENDENCY_UNLOCKED`
- `BOUNDARY_CHANGED`
- justified `SCHEDULED_REVIEW`

The compounding asset is a provenance-bearing **Personal Decision Model** containing what the user believed, chose, executed, learned and later reversed.

Strong test:

> **Would the next recommendation materially degrade if the user's first 11 months of real decision / action / outcome history disappeared?**

If no, the product has not built a compounding retention asset.

## Current lifecycle state

**FIELD — paid authority-wedge + longitudinal retention validation**

The next justified evidence is:

1. suitable ICP participants;
2. personalized Wizard-of-Oz value;
3. real paid continuation / refusal evidence;
4. a second material decision event where possible;
5. evidence that prior decision lineage materially improves the next decision.

Do not broaden to generic life decisions or build a full autonomous decision engine before these gates survive.
