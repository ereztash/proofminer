# ProofMiner

ProofMiner is currently being rebuilt using a **Personal Decision Intelligence** architecture with a deliberately narrow first commercial domain:

> **Professional Market Position for independent experts, consultants and fractional leaders at a professional inflection point.**

The product is not being broadened to generic life decisions.

`Personal Decision Intelligence` is currently an internal category / architecture label, not assumed to be the best customer-facing category.

---

## Current conscious problem hypothesis

> **I am trying to change how the market sees / chooses me. There are several plausible things I could do, but I do not know which move deserves my limited time, money and attention now, what should wait, or what evidence should make me change course.**

Authority-building may be one important mechanism / target state, but the product should not force every buyer to describe the problem as `I want to become an authority`.

---

## Two teloi

### User telos

Improve the user's representation of the professional market-position problem and allocation of scarce resources toward the strongest grounded path, while preserving decision authorship and learning from real outcomes.

### Business telos

Capture a sustainable share of the value created by those improved decisions through a repeatable commercial model **without changing recommendation logic to maximize engagement, billing duration or dependency**.

If these conflict, recommendation integrity wins and the commercial model must change.

## Current state model

```text
professional inflection point
→ freeze boundary + prior representation + prior allocation
→ person + field research
→ frame the live decision
→ use the least-complex sufficient reasoning process
→ grounded, contestable representation / allocation change
→ user commitment + action
→ evidence across affected market / authority surfaces
→ learning
→ next decision in the episode
↺
```

The system must preserve the difference between:

- user understanding and user compliance;
- decision and outcome;
- memory and transferable evidence;
- current state and historical state.

## Compounding state

The long-term object is not a static personality-style `Decision Profile`.

It is a **versioned Personal Decision State + lineage** containing:

- goals / boundaries at the time;
- prior representation;
- considered alternatives;
- resource commitments;
- decision rationale;
- user-endorsed criteria;
- actual execution;
- observed outcomes;
- reversals;
- market / field changes;
- transferability state for reusing prior evidence.

Long-term value requires both memory and selective forgetting / scoping.

Strong test:

> **Which parts of prior history materially improve this later decision — and which parts must be ignored because the context changed?**

If history is either useless or indiscriminately reused, the compounding thesis fails.

## Business model hypotheses

### Current priority — Active Transition Episode

First executable FIELD cell:

> **90-Day Professional Market Position Decision Intelligence Pilot — $1,500 total.**

Human-in-loop is explicit. The pilot includes initial person/field/decision-state work, the first material allocation decision, up to three additional consequential decision reviews triggered by real events, outcome/evidence review, and persistent lineage.

The $1,500 price is a research cell, not validated pricing. Do not discount within the first 3–5 suitable offers merely to increase conversion.

## Retention thesis

Reject artificial daily engagement.

There are three forms of retention:

1. **within-episode continuation** — decision #2 / #3 during an active transition;
2. **between-episode persistence** — history and unresolved state remain available while the product is quiet;
3. **reactivation** — a new consequential decision, outcome, dependency or boundary change reopens active use.

A quiet user is not automatically a failed user.

Ongoing `monitoring` counts as value only when new decision-relevant information actually enters the system through a connected signal, returned outcome, external research update or explicit human review.

---

## Current differentiation hypothesis

> **A domain-grounded professional-transition decision system that freezes the user's prior representation and allocation, researches external market state, makes a contestable allocation decision, records actual execution / outcomes, and uses only transferable longitudinal evidence to improve later decisions while preserving user authorship.**

Every clause remains falsifiable. Collapse complexity that does not change decisions or willingness to pay.

---

## Current lifecycle state

**FIELD — paid Professional Transition Episode + decision-density + longitudinal transferability validation**

Highest-value evidence now:

1. real suitable participant;
2. one real personalized decision change;
3. real $1,500 paid continuation / refusal;
4. naturally occurring decision #2;
5. compare longitudinal vs fresh analysis;
6. test whether prior history is actually transferable;
7. observe preferred billing unit: episode / month / decision / adviser relationship;
8. observe the participant's own language for the job.

Do not broaden the product, polish production UI, or build a full autonomous decision engine before these gates survive.
