# ProofMiner

ProofMiner is being rebuilt as a **Personal Decision Intelligence** architecture with a deliberately narrow first commercial domain:

> **Professional Market Position for independent experts, consultants and fractional leaders at a consequential professional transition.**

The product is not being broadened to generic life decisions.

`Personal Decision Intelligence` is an internal architecture / category label, not assumed customer language.

---

## Current conscious problem hypothesis

> **I know roughly where I want to go professionally. There are several plausible things I could do, but I do not know what deserves my limited time, money and attention now — or what I am missing because I am too close to my own business.**

Authority may be one target state or mechanism inside this job. It is not mandatory buyer language.

---

## User telos

Help the professional improve the **representation** of the transition and the **allocation** of scarce resources toward a desired market / opportunity state, while preserving decision authorship and learning from real outcomes.

The system should exploit useful expertise already embedded in the user's real professional practice without treating that expertise as automatically transferable truth.

## Business telos

Capture a sustainable share of created value without distorting recommendations to maximize engagement, billing duration, analytical complexity or dependence on system authority.

Recommendation integrity wins when the two teloi conflict.

---

# Core architectural shift — characterization before broad intake / research

The current central mechanism is not a universal onboarding questionnaire.

The system should select the **characterization process** capable of revealing the next decision-relevant distinction.

When the user's own professional expertise is material, the canonical loop is:

```text
REAL PROFESSIONAL CASES
        ↓
EXTRACT
how the person actually diagnoses / decides / creates value
        ↓
ABSTRACT
minimum Professional Operating Model
        ↓
SELF-APPLY
use that process on the person's own business / transition
        ↓
CHALLENGE
where does the lens fail / not transfer?
        ↓
GAP
what is still unknown that can change the decision?
        ↓
TARGETED EXTERNAL RESEARCH
        ↓
LIVE DECISION
        ↓
ACTION / OUTCOME / LEARNING
```

Example:

```text
project manager
→ reconstruct how they manage real projects
→ scope / dependencies / critical path / capacity / risk
→ treat their own transition as a project
→ identify what the analogy misses
→ research only unresolved market facts
```

or:

```text
marketer
→ reconstruct how they diagnose clients
→ audience / problem / positioning / offer / channel / funnel
→ apply the process to their own business
→ challenge marketing-lens capture
→ research buyer / market facts that remain external
```

`SELF-APPLICATION` is not a default truth source. It is a bounded characterization mechanism.

---

## Characterization process families

The system may select the smallest useful family:

- direct clarification;
- critical-case reconstruction;
- cross-case abstraction;
- self-application / role reversal;
- resource / decision reconstruction;
- external mirror;
- competing-lens / boundary challenge;
- backward-from-O.

At every additional question / process:

> **What live representation or decision could this change?**

If none, stop characterization.

---

## Current state model

```text
professional transition
→ O / target state / boundary
→ freeze prior representation + allocation
→ select characterization process
→ extract latent professional operating model when useful
→ self-apply when useful
→ challenge transferability / blind spots
→ identify decision-relevant unknowns
→ targeted external research
→ frame live decision
→ least-complex sufficient reasoning process
→ grounded, contestable representation + allocation decision
→ user commitment + action
→ outcome evidence
→ learning / next decision
↺
```

The system must preserve distinctions between:

- user's expertise and external market fact;
- user understanding and user compliance;
- analogy and transferability;
- decision and outcome;
- memory and reusable evidence;
- current state and historical state.

---

## Decision-directed research

The product should not start with `research the market deeply`.

Every material search must originate in a live unknown:

```text
DECISION
→ UNKNOWN THAT COULD FLIP / CHANGE IT
→ RESEARCH QUESTION
→ SOURCE / OBSERVATION
→ INFERENCE
→ TRANSFERABILITY
→ DECISION USE
```

Broad search volume is not a product objective.

---

## Measurement

Observe separately:

- Characterization Unique Contribution;
- Professional-Model Transferability;
- Representation Delta;
- Decision Authorship / Contestability;
- Decision Delta;
- Priority Delta;
- Resource Allocation Delta;
- Research Avoided / Newly Required;
- Reversal / Regret;
- Decision #2 / #3 rate;
- History Materiality Rate;
- Stale-History Rejection Rate;
- Paid Continuation / Reactivation.

These are evaluation measurements, not recommendation objectives.

---

## Compounding state

The long-term object is a **versioned Personal Decision State + lineage**, not a timeless personality / Decision Profile.

It may contain:

- goals / boundaries at the time;
- representation snapshots;
- Professional Operating Model hypotheses + source cases;
- transferability state;
- alternatives / decisions;
- resource commitments;
- actual execution;
- outcomes;
- reversals;
- market / field changes.

Strong test:

> **Which prior evidence materially improves the next decision — and which prior evidence must be rejected because the context changed?**

---

## Business model hypothesis

Current executable FIELD cell:

> **90-Day Professional Market Position Decision Intelligence Pilot — $1,500 total.**

Human-in-loop is explicit.

The paid pilot now includes characterization **only when it changes the live decision**. The user is not paying for an interesting methodology-extraction exercise.

Other models remain live: active/pause, episodic paid Decision Review, or ongoing concierge if human judgment proves to be the durable product.

Monthly subscription is not an invariant.

---

## Current differentiation hypothesis

> **A professional-transition decision system that can discover how the user already solves systems for others, selectively apply that expertise to their own system, challenge where the transfer fails, research only the remaining decision-relevant unknowns, and turn the result into a contestable resource-allocation decision that learns from real outcomes.**

Every clause is falsifiable.

If a strong simple intake / advisor reaches the same decision at lower cost, collapse the characterization architecture.

---

## Current lifecycle state

**FIELD — characterization-first paid Professional Transition validation.**

Highest-value evidence now:

1. suitable professional at a live transition;
2. frozen pre-intervention representation + allocation;
3. strong simple intake/advisory result;
4. characterization-first result using real professional cases only where justified;
5. measure whether characterization reveals a unique material distinction;
6. actual decision / allocation change;
7. authorship / contestability;
8. real $1,500 continuation / refusal;
9. execution / outcome;
10. decision #2 and transferability of prior learning.

Do not build another UI prototype, a broad intake engine or a full autonomous research agent before this survives FIELD.
