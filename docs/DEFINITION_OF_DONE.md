# O recalled

Reduce avoidable commitment to weakly grounded strategic bets during consequential professional transitions.

The first-session job is:

> **Before the user pays the full cost of a plausible plan, make visible what the plan is implicitly betting on, connect that bet to evidence / unknowns, and produce a contestable `KEEP`, `CHANGE` or `TEST_FIRST` commitment outcome.**

The product does not pass because it generated a diagnosis, recommendation, canvas, methodology, simulation or surprising insight.

# Canonical first-session hierarchy

```text
PROFESSIONAL TRANSITION
→ CURRENT PLAN / ACTIONS
→ MATERIAL RESOURCE EXPOSURE
→ FROZEN PRE-SYSTEM COMMITMENT
→ CANDIDATE IMPLIED BET
→ USER CORRECTION / CONTESTABILITY
→ COMPETING EXPLANATION WHEN REQUISITE
→ DECISION-RELEVANT EVIDENCE / UNKNOWN
→ KEEP | CHANGE | TEST_FIRST
→ REVERSAL CONDITION
→ REAL ACTION / FIELD OBSERVATION
→ LEARNING / NEXT COMMITMENT
```

# Hard gates

1. **Baseline before influence.** Preserve the real pre-system plan before advice.
2. **Plan-linked inference.** A surfaced bet must be traceable to actions / resource exposure.
3. **No mind-reading.** Say `your plan behaves as if`; do not attribute an inferred belief to the user as fact.
4. **Contestability.** User can correct / reject the inferred bet cheaply.
5. **No root-cause theater.** Alternative explanations remain hypotheses until evidence supports them.
6. **Evidence relations.** Distinguish SUPPORTS / CONTRADICTS / NON_DISCRIMINATING / MISSING.
7. **Evidence classes.** F0/F1/F2/F3/F4 authority boundaries remain explicit when material.
8. **Outcome discipline.** The reveal ends in `KEEP`, `CHANGE` or `TEST_FIRST` only.
9. **Real consequence.** CHANGE changes an action / sequence / allocation / prerequisite / evidence request.
10. **Test discipline.** TEST_FIRST is smaller than the commitment it protects and can discriminate a load-bearing uncertainty.
11. **No analysis paralysis.** Cheap reversible action that teaches faster should normally proceed rather than be delayed by a ceremonial test.
12. **Reversal condition.** Every load-bearing outcome states what could reopen it.
13. **Authorship.** User agreement is not counted as validation or authorship by itself.
14. **Substitute test.** Compare against a strong simple advisor / LLM process.
15. **FIELD truth.** Payment, actual behavior, execution, market response and later outcome remain FIELD-only.

# Capability routing after the Gate

Use only when needed to change the current bet / evidence / commitment outcome:

- Characterization / ProfessionalOperatingModel;
- self-application;
- external research;
- dependency mapping;
- richer resource allocation;
- Meta-Decision routing;
- Strategic Wind Tunnel;
- synthetic stakeholders as F4 hypothesis generators.

A capability has no right to run merely because it exists.

---

# Structural falsification

Reject at least:

- advice before baseline;
- inferred bet with no trace to the plan;
- system inference rendered as user belief;
- unsupported alternative rendered as diagnosis;
- reveal with no commitment consequence;
- TEST_FIRST with no discriminating result;
- test larger than the commitment it protects;
- external research with no bet / decision it can change;
- synthetic output upgraded to market evidence;
- KEEP treated as product failure;
- surprise treated as success;
- richer workspace protected against a simpler mechanism that produces the same outcome.
