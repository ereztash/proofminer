# ProofMiner — Indispensability DOD v2

Date: 2026-08-16

## Governing ambition

> **Unskippable by value, skippable by design — at the capability level, not the app level.**

A dedicated ProofMiner application is not required to survive. The capability may live inside another surface or disappear into infrastructure.

The target is:

> After experiencing real value on one recurring commitment class, a suitable user does not want to make that class of commitment again without the decision-safety capability.

The user must always be able to bypass it.

---

# Indispensability is NOT

- opening ProofMiner frequently;
- daily / weekly active use;
- streaks or notification response;
- attachment to a dashboard;
- discomfort because an interface disappeared;
- forced approvals;
- artificial workflow dependency.

---

# Indispensability IS

Behavioral evidence that when the capability is absent, the user:

- recreates part of the check manually;
- deliberately seeks a substitute before committing;
- postpones a material commitment because the check is unavailable;
- explicitly accepts the uncovered risk and proceeds;
- pays to preserve the capability;
- or exhibits measurable degradation in commitment quality / learning.

If a general AI + template replaces it at equal cost and quality, ProofMiner has no unique product claim.
